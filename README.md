## Run locally

    git clone https://github.com/kumarakshay7/akshay-portfolio.git
    cd akshay-portfolio
    pip install -r requirements.txt
    streamlit run app.py

For the contact form, configure these Streamlit secrets:

    EMAIL_ADDRESS = "your-email@example.com"
    EMAIL_APP_PASSWORD = "your-app-password"
